# 🎬 Movie Lens Dashboard

An interactive Power BI dashboard designed to explore and analyze classic movies released until the year 2000. This project visualizes key trends in movie characteristics, user interests, and demographic-based rating patterns.

---

## 📊 Project Overview

This dashboard was created as part of a school assignment to demonstrate data visualization and storytelling through Power BI. It offers insights into:

- Popular genres and their average ratings
- How different age groups and genders rate movies
- Trends in movie releases and viewer preferences over time

---
